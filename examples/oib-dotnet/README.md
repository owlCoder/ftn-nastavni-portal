# OIB .NET primeri

Osam malih, samostalnih C#/.NET projekata prati teme računarskih vežbi iz Osnova informacione bezbednosti. Svaki projekat može da se pokrene zasebno i namerno je dovoljno mali da se odluka, kontrola i dokaz vide bez dodatne infrastrukture.

```bash
dotnet run --project vezba-01-identitet-rbac/Oib.Vezba01.csproj
```

Za proveru svih primera pokrenite `./verify.sh` na macOS/Linux sistemu ili pojedinačne `dotnet build` komande.
